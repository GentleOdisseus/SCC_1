# ADR-0002: Commit/PR — наблюдение, а не прогресс

- Статус: принято
- Дата: 2026-09-27

## Контекст
Размер diff и LOC не отражают продвижение к цели; самооценка агента нестабильна.

## Решение
Git/CI/review/deploy/acceptance — измерительные события с весами доверия. Различаем D_estimated и
D_verified; Estimation Gap — отдельная метрика. PR — кандидат `S_candidate`, становится `S_verified` после evidence.

## Последствия
- Нужен Evidence-слой (`src/scc/evidence`) и калибровка весов (эксперимент E5).
- Контроллер может управлять Git-стратегией (split/merge PR).
