# ADR-0001: D — кортеж, а не число

- Статус: принято
- Дата: 2026-09-27

## Контекст
Одно число D не различает «далеко», «дорого добраться», «неизвестно насколько далеко». D может расти
при обнаружении скрытой работы, что не является регрессом.

## Решение
`D(S, G) = (D_completion, D_cost, U_D)`. Цель — область G; D_completion по взвешенным проверяемым
требованиям с hard constraints; D_cost — оценка cost-to-go; U_D — неопределённость.

## Последствия
- Контроллер принимает решения по трём осям.
- Визуализация: положение = completion, траектория = cost, ореол = uncertainty.
